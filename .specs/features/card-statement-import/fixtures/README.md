# Sanitized Card Statement Fixtures

These fixtures are synthetic files derived from the real Nubank and Bradesco export shapes reviewed on 2026-08-03. The real files in `Downloads` contain personal financial data and must not be committed.

## Files

| File | Purpose |
| --- | --- |
| `nubank-statement-sanitized.csv` | Simple UTF-8 comma CSV matching the Nubank column shape. |
| `nubank-statement-expected.json` | Expected normalized rows for parser tests. |
| `bradesco-statement-sanitized.csv` | Git-normalized fixture matching the Bradesco section/delimiter shape. |
| `bradesco-statement-expected.json` | Expected section classification and normalized rows for parser tests. |

## Bradesco Encoding Note

The real Bradesco export was ISO-8859-1 with `CR` line endings. This repo stores fixtures with normal Git text handling. Parser tests should either re-encode this fixture according to the expected metadata or keep a generated byte fixture outside manual editing.
